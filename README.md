## 🛠️ Stack Tecnológico & Arquitectura

Este portafolio está optimizado para garantizar velocidad de carga, diseño responsivo y compatibilidad multiplataforma:
* **Estructura:** HTML5 Semántico (con soporte nativo para Modo Oscuro/Claro mediante LocalStorage).
* **Estilos:** Tailwind CSS (vía CDN) + Hojas de estilo personalizadas (`styles.css`).
* **Interactividad:** Vanilla JavaScript (`app.js`) para navegación dinámica, menú móvil y control de temas.
* **Iconografía:** Lucide Icons.
* **Despliegue:** GitHub Pages (CI/CD nativo).
